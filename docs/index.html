Feature parity

Everything the original does.
None of the framework.

The same workflow and safeguards as Win32DiskImager 1.0.0, rebuilt on the Win32 API.

Read · Write · Verify

Block-by-block transfers in 1024-sector chunks, with a cancelable progress bar and the exact sector of the first mismatch.

MD5 · SHA1 · SHA256

Hash the selected image with Windows CNG/BCrypt and copy the digest to the clipboard in one click.

Allocated partitions only

Read just the defined partitions: parse the MBR and stop at the end of the last partition instead of copying the whole device.

Hot-plug aware

Removable, USB, SD and MMC devices are enumerated at startup and refreshed through WM_DEVICECHANGE.

Drop, type or pass a path

Drag an image onto the window, browse for it, or pass it on the command line. The last folder is remembered in the registry.

English & 简体中文

Every caption and message is a resource string. The UI follows the Windows language or an explicit --lang override.

Native by design

A dialog, not a framework.

The entire interface is a single DIALOGEX resource. Every control is a stock Win32 class — nothing is owner-drawn, themed by hand, or wrapped in a UI toolkit.

  • No Qt runtime, no Qt DLLs, no plugin folders.
  • Scripted in Win32DiskImager.rc; captions applied at runtime for i18n.
  • Common Controls v6 manifest for native Windows 10/11 visuals.
  • Statically linked C/C++ runtime — copy one exe and run it.

Build

Two commands, one exe.

All you need is a MinGW-w64 toolchain with g++ and windres. build.bat compiles the resources and links one executable.

  1. Get the source. Clone this repository or download its archive.
  2. Run build.bat. It compiles the resources and links Win32DiskImager.exe.
  3. Run as administrator. Raw device access requires elevation; the manifest requests it.
rem from the repository root
build.bat

rem English UI
Win32DiskImager.exe --lang en

rem Chinese UI
Win32DiskImager.exe --lang zh-CN
Writing a physical device overwrites it. Double-check the target drive before you press Write.

Internationalization

One dialog, every language.

Strings live in STRINGTABLE blocks in the resource script. The dialog is shared; captions are loaded with LoadStringW after SetThreadUILanguage.
